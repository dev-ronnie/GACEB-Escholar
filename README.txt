HOW TO USE
=====================================

1. Download and unzip this folder.

2. Go to: https://github.com/dev-ronnie/GACEB-Scholar

3. Upload / replace ALL these files:
   - index.html
   - sciences.html
   - arts.html
   - about.html
   - account.html
   - styles.css
   - script.js

4. Keep your existing files:
   - config.js
   - account-server.js
   - gaceb-scholar-logo.png
   - sr-gauge.jpg
   - recognition photos

5. Commit the changes on GitHub.

6. Netlify will update the live site automatically.
